with personal profile, certificate display, game development display, software development display, contact information, and blog system,
There is also a complete account system. I have basically stepped on all the pitfalls that personal websites need to overcome, and I have also listed the controls and displays that are often used in personal websites. 
If you need them, you can immediately pull them for research. If it can help you, I hope you can give me a star.
